                  GPU servers

                  Machines running the clone server (clone/) speak cloned voices. Each job goes to the first server here that's answering, so one can stand in when another is off.

                    How to set up a GPU server

                    Any PC with a graphics card of 8 GB or more can be one. Run one line on it. It downloads what it needs, starts the server, and ends by showing the address and token: paste them into Add a GPU server below. Running it again updates the server and keeps its token.

                    Windows, natively (NVIDIA or AMD Radeon)

                    No WSL or Docker; it starts by itself when Windows does. In PowerShell as administrator:

                    irm https://raw.githubusercontent.com/kmmarin/AudioBookForge/main/deploy/gpu-server.ps1 | iex

                    Windows with WSL and Docker (NVIDIA)

                    The same in WSL 2. It installs WSL if it's missing, and opens the port to other machines. In PowerShell as administrator:

                    & ([scriptblock]::Create((irm https://raw.githubusercontent.com/kmmarin/AudioBookForge/main/deploy/gpu-server.ps1))) -Mode wsl

                    Linux with Docker (NVIDIA)

                    It installs Docker and NVIDIA's container toolkit if they're missing:

                    curl -fsSL https://raw.githubusercontent.com/kmmarin/AudioBookForge/main/deploy/gpu-server.sh | sudo bash

                    On this machine, beside Forge

                    With an NVIDIA card of 12 GB or more, Forge's installer runs it here by itself (CLONE_LOCAL=auto), and it's listed above.

                    The first cloned voice it speaks downloads the voice model, about 4.5 GB.
